# Hostile review of v0.2 — accepted corrections and action record

The full hostile review was supplied externally after v0.2. This file records the changes accepted into the next protocol; `PREREGISTRATION_V0.3.md` is authoritative for the experiment.

Accepted without reservation:
- v0.2 is an integration/falsification-pilot result, not scientific evidence of compositional generalization;
- fix overlapping accuracy/escalation reporting with a full outcome confusion matrix;
- treat the six filesystem held-outs as correlated observations of one acquired family-level capability;
- withdraw lexical-near results from compositional evidence;
- make k-NN selective by sweeping an abstention threshold and compare risk/coverage/AURC;
- externalize held-out language/gold provenance and independently review grading/splits;
- replace the 3.33 artifact ratio with compression/MDL, growth, and marginal-supervision measurements;
- add frozen knockout + autonomous recovery + semantic-floor + seed-only + information-audit controls;
- grade recovery by multi-fixture denotation and treat byte-identical recovery as an audit trigger;
- explicitly test whether intent patterns grow one-per-task-family;
- run one decisive primitive-holdout experiment before scaling the benchmark.

Modification to the review:
- O(N) growth is not intrinsically cache behavior when N represents genuinely new semantic concepts. The key falsifier is approximately one new task-specific durable artifact for each new *composition of already-known semantics*. v0.3 conditions growth measurements on semantic novelty.
- host/runtime primitives remain exact machinery; benchmark capabilities must not force rediscovery of functionality the architecture intentionally delegates to the host.

Not accepted as a project pivot yet:
- calibrated abstention is an important property and will be measured fairly, but v0.3 continues to test the central dynamic knowledge -> composition -> executable Blueprint hypothesis rather than redefining EKG primarily around abstention.
