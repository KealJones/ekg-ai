# v0.9.6 — EKG local CLI

This checkpoint turns the research runtime into something a human can directly run and poke without writing custom Node scripts.

Evidence:
- `npm run ekg` starts a persistent REPL.
- default brain file: `ekg-data/brain.json`;
- typed runtime inputs can be prompted or supplied as `:: [inputs]`;
- manual synonym teaching persists across a complete process restart;
- compatible learned lexical concepts can resolve to acquired `ProgramBlueprint` calls;
- 186/186 fast tests pass;
- frozen benchmark report remains 4/5 held-out vs 0/5 memorize baseline.

Limitations:
- the local CLI does not yet have an external LLM Teacher transport;
- natural-language argument structure is still scaffolding: not every fully literal English sentence is converted directly into all Blueprint inputs;
- multi-input learned procedures can always be executed with `/run`, while generalized language-role binding for arbitrary learned program signatures remains future work.
