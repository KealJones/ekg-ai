# v0.9.1 — Ladybug embedded brain + authorized remote lab

## What changed

- LadybugDB is the preferred embedded durable `GraphStore` realization.
- `MemoryGraphStore` remains the zero-install fallback.
- ArcadeDB remains an optional network/server adapter.
- Search v2 can derive operation priors from durable Ladybug execution episodes through Cypher.
- High-value episode fields (`subjectId`, `status`) are projected into native typed graph properties; arbitrary attrs remain losslessly serialized until they prove query-hot enough to promote.
- `.github/workflows/ekg-remote-lab.yml` provides an authorized internet-enabled execution lane that installs the native Ladybug package, runs a required real persistence/Cypher integration, runs the living suite, benchmarks Search v2, and uploads the test brain/logs.
- External integrations and historical expensive experiments are separated from normal unit/development tests.

## Local evidence in the restricted ChatGPT sandbox

- `npm run build`: PASS
- `npm test`: **185/185 PASS, 0 skipped**
- `npm run test:ladybug`: **3/3 PASS**
- `npm run test:ladybug:integration`: **1 intentional skip** because `@ladybugdb/core` cannot be fetched in this restricted shell
- Search v2 benchmark: legacy depth-3 failure proof ~5.48 s vs v2 ~109 ms, roughly **50x faster** on this run.

## Native proof contract

The GitHub remote lab sets `EKG_REQUIRE_LADYBUG=1`. The integration test is therefore fail-closed there: missing/unloadable native Ladybug cannot become a green skip. It must open an on-disk database, write semantic entities/relations/episodes, execute raw Cypher, close, reopen, and prove persistence.
