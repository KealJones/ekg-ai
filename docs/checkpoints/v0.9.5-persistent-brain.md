# v0.9.5 — Persistent Brain

The runnable EKG no longer loses acquired knowledge when the Node process exits.

## Storage model

`FileBrain` owns the existing fast in-process stores and backs them with one ordinary JSON file (`ekg-data/brain.json` by default, override with `EKG_BRAIN_PATH`). Construction loads the file if present. Mutations atomically rewrite it using a temporary file plus rename.

Persisted together:

- graph entities and relations;
- learned executable Blueprints / procedures;
- successful and failed execution-experience traces;
- controller RUN / ADAPT / BUILD / TEACH episodes.

Host/native capabilities are re-created from the current runtime on startup; acquired procedures and lived experience are restored from disk.

## Durability gate

A test launches one Node process, teaches a novel executable procedure, records experience, and exits. A second independent Node process loads the same brain file and executes the learned procedure Teacher-OFF while also verifying graph identity, experience, and episode restoration.

Until this test existed, prior uses of “durable” meant durable only inside a running process. v0.9.5 corrects that architectural mismatch.
