# v0.3 primitive-holdout experiment — preflight failure

## Status

**No scored EKG benchmark run was performed.** The experiment was stopped during outcome-blind preflight.

## What failed

The independently sourced/adjudicated 120-item NL2Bash benchmark satisfied the item-count, family-count, fixture-count, reference-spec, denotation-variation, and frozen-selection integrity gates. A later denotation-data-dependency audit found that the benchmark assumes a generic filesystem semantic substrate that frozen checkpoint-0 EKG does not actually possess.

The audit deliberately ignores action/output tails when they merely consume an already-selected denotation. A non-held-out semantic counts as a confound only when it is required to derive the scored denotation itself.

Against the actual checkpoint-0 reusable semantic surface, **0/120 items are clean** under that rule. The dominant missing base semantics are generic filesystem enumeration usable by semantic composition, recursive traversal, file metadata access, glob/predicate filtering, content access, and path/permission/ownership predicates.

This is stronger than the earlier 82/120 broad audit: removing action-tail false positives did not rescue the design because the missing substrate lies upstream of the held-out primitive.

## Interpretation

v0.3 cannot test the intended causal claim:

> After exactly one lesson for held-out primitive X, can EKG compose X with semantics it already knew at checkpoint 0?

The benchmark instead requires X plus substantial filesystem semantics that were not already present. Any scored failure would therefore be unattributable.

## Decision

The v0.3 experiment is recorded as a **preflight failure**, not a negative result for EKG. The 120 independently authored/adjudicated/fixtured items are preserved unchanged as research artifacts. No thresholds are relaxed and no subset is scored.

The next experiment version must freeze and independently verify an explicit base-semantic vocabulary *before* held-out item selection. Only items whose non-held-out denotation dependencies are inside that vocabulary may enter the scored benchmark.
