The first real NL2Bash corpus run exposed false positives in the frozen candidate-discovery heuristic for `predicate.within_closed_int_window`: shell redirections and angle-bracket placeholders were being interpreted as numeric comparison syntax. This was a harness bug, not a learner result.

The selector was tightened to require paired `find` time predicates with token boundaries. The corrected external supply is still above the preregistered floor: 71 candidates / 62 unique commands for the closed-window primitive; the other two primitive supplies are unchanged and remain well above 40.

A deterministic 180-record review pack (60 candidates per frozen primitive, evenly spread through the externally sourced candidate pool) is generated outside the scored benchmark. It contains external NL2Bash utterance + Bash command pairs and blank review fields. An independent reviewer must reject semantic false positives and assign family IDs before any item can enter the scored benchmark. EKG/Teacher must not author the scored gold.
